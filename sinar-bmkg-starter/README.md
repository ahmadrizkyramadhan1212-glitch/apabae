- Rencana sprint dan prompt: `docs/SPRINTS.md`
- Setup alat dan perintah: `docs/SETUP.md`
- Aturan untuk AI coding: `CLAUDE.md` (Claude Code) atau salin isinya ke `.cursorrules` (Cursor)

Mulai dari `docs/SETUP.md`, lalu kerjakan Sprint 0 di `docs/SPRINTS.md`.
